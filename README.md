# 당직 누구?

### 오늘 누가 당직이지? 내 차례는 언제지?

매달 올라오는 엑셀 명단을 뒤적이지 않아도 됩니다. **오늘의 당직, 월별 일정, 내 당직 이력과 통계**를 한곳에서 확인하세요.

[**당직 누구 바로 사용하기 →**](https://hanjjaem.github.io/danjik-nugu/)

[![당직 누구 서비스 화면 목업: 이름 검색, 오늘의 당직, 월별 일정](docs/readme-preview.png)](https://hanjjaem.github.io/danjik-nugu/)

**이름만 검색하면 내 기록까지 바로.** 부산광역시 동구의 당직 명단을 더 빠르고 편하게 확인하기 위해 만들었습니다.

### 한재림을 검색하면 이렇게 이어집니다

![한재림 검색 후 캘린더 일정 강조, 당직 횟수와 월별 통계, 당직 이력, 전체 통계의 선택된 행까지 보여주는 실제 앱 시연](docs/readme-demo.gif)
